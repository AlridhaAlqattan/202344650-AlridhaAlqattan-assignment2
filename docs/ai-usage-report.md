# AI Usage Report

##  Introduction

AI tools were used as supplementary resources during the development of this personal portfolio website. Their purpose was to support learning, assist with debugging, and improve the understanding of React and JavaScript concepts. As well as writing documentation.

##  AI Tools Used

**Tool:** ChatGPT

ChatGPT was used to ask questions about React components, JavaScript functionality, troubleshooting, and documentation. It served as a learning and problem-solving aid rather than a replacement for understanding the code.

**Tool:** Github Copilot

Copilot was used for completing code and for suggesting code structures for
certain functions, as well as easier redundant code writing (For example,
writing multiple p elements)

##  Areas of AI Assistance

### React Components

AI assistance was used to understand how React components are organized and how data and functions can be passed between components.

### State and Effects

Questions were asked about React's useState and useEffect hooks, particularly how component state is managed and how date and time information can be updated.

### Debugging and Problem-Solving

AI assistance helped investigate programming issues and explain possible solutions. Suggestions were reviewed against the project's requirements before being used.

###

AI helped in suggesting some styles in designing interactive elements like
buttons or adding hover effects to boxes.

### Documentation

AI assistance was used to help write the documents like README, ai usage report, Academic Intergity Report, and Technical documentation.

##  Review and Adaptation of AI Suggestions

AI-generated suggestions were treated as guidance rather than automatically accepted solutions. Relevant suggestions were reviewed and adapted to fit the project's existing structure and requirements.
The goal was to understand why each solution works and how it affects the application.

##  Limitations

AI-generated responses may contain incorrect assumptions, or code that does not match the project's environment. Therefore, AI assistance does not replace testing, debugging, or independent verification.


##  Learning Outcomes

Using AI as a supplementary learning tool helped reinforce concepts related to React components, state management, effects.

The development process also emphasized the importance of reviewing suggested solutions, understanding the resulting code, and documenting the use of AI transparently.
